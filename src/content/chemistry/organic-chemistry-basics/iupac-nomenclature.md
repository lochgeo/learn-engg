## Why a naming system exists

A structure can be drawn in many ways, but a chemical name must point to exactly one structure. IUPAC nomenclature is a set of rules for building that unique name. Once you know the rules, a name is a compressed structural formula — and reading it back into a structure is a skill JEE tests constantly.

<learning-block type="concept" title="Anatomy of a name">

**prefix + word root + primary suffix + secondary suffix**

- **Word root** gives the number of carbons in the parent chain: meth(1), eth(2), prop(3), but(4), pent(5), hex(6), hept(7), oct(8), non(9), dec(10).
- **Primary suffix** shows saturation: -ane (single), -ene (double), -yne (triple).
- **Secondary suffix** names the principal functional group: -ol, -al, -one, -oic acid, -amine.
- **Prefixes** name substituents and lower-priority groups: methyl-, chloro-, hydroxy-, nitro-.

Example: **3-methylbutan-2-ol** = a four-carbon chain (but), all single bonds (an), an –OH at C2 (ol), and a methyl branch at C3.

</learning-block>

## 1. The rules, in the order you apply them

1. **Find the parent chain.** It must contain the principal functional group and the maximum number of multiple bonds, and it should be the longest such chain. The chain may bend; it need not be drawn horizontally.
2. **Number the parent chain.** Give the principal functional group the lowest possible locant. If there is no principal group, give the multiple bonds the lowest set of locants. Then give the substituents the lowest set.
3. **Name substituents as prefixes** and list them **alphabetically**. The multiplying prefixes di-, tri- and tetra- are **not** counted when alphabetising, but the substituent name itself is.
4. **Attach locants.** Separate numbers by commas and numbers from words by hyphens: 2,3-dimethylbutane.
5. **Repeat substituents** with di-, tri-, tetra- and repeat the locant: 2,2-dimethylpropane.

When two numbering directions give different locant sets, compare the sets term by term and choose the one with the lower number at the **first point of difference**: 2,3,5 beats 2,4,5.

## 2. Principal-group priority

When several groups are present, only the highest-priority one becomes the suffix; the rest appear as prefixes.

| Priority | Group | Suffix |
| --- | --- | --- |
| 1 | –COOH | -oic acid |
| 2 | –SO₃H | -sulphonic acid |
| 3 | –COOR | alkyl -oate |
| 4 | –COX | -oyl halide |
| 5 | –CONH₂ | -amide |
| 6 | –C≡N | -nitrile |
| 7 | –CHO | -al |
| 8 | >C=O | -one |
| 9 | –OH | -ol |
| 10 | –SH | -thiol |
| 11 | –NH₂ | -amine |
| 12 | C≡C | -yne |
| 13 | C=C | -ene |
| 14 | –X, –NO₂, –OR, alkyl | prefix only |

The carbon of –COOH, –CHO, –COOR, –CONH₂ and –C≡N is always counted as part of the parent chain and is always C1 for that group.

## 3. Multiple bonds

- One double bond: -ene; two: -diene; three: -triene.
- One triple bond: -yne; two: -diyne.
- If both are present, the name ends **-en…-yn…**, with the double bond cited first. If numbering is tied, the double bond takes the lower locant.

<learning-block type="example" title="Tie-break in action">

CH≡C–CH₂–CH=CH₂ has multiple bonds at positions 1 and 4 counting from either end. Because the double bond gets the lower locant on a tie, the name is **pent-1-en-4-yne**, not pent-4-en-1-yne.

</learning-block>

## 4. Rings and benzene

- A saturated carbon ring is named **cyclo** + root + suffix: cyclohexane, cyclopropane.
- Number the ring to give substituents the lowest locants; a single substituent needs no locant: methylcyclohexane.
- Two substituents: 1,2-dimethylcyclohexane. If the set is tied, give the lower locant to the substituent cited first alphabetically.
- Benzene is usually the parent: methylbenzene, 1-ethyl-3-methylbenzene.
- Some trivial benzene names are retained and expected: phenol (hydroxybenzene), aniline (aminobenzene), benzaldehyde, benzoic acid, benzenesulphonic acid, toluene (methylbenzene), styrene (ethenylbenzene).

## 5. Worked examples

### Example 1: a branched alkane

CH₃–CH(CH₃)–CH₂–CH₂–CH₃

Longest chain: five carbons (pentane). Numbering from the left puts the methyl at C2; from the right it would be at C4. Choose 2.

**2-methylpentane.**

### Example 2: two identical branches

CH₃–CH₂–C(CH₃)₂–CH₂–CH₃

Longest chain: five carbons. The two methyls are on the same carbon, C3.

**3,3-dimethylpentane.**

### Example 3: alkene versus substituent

CH₂=C(CH₃)–CH₂–CH₃

The double bond must get the lowest locant, so number from the left: C1=C2, methyl at C2.

**2-methylbut-1-ene.** Numbering from the right would give a double bond at C2, which is worse.

### Example 4: principal group wins

HOCH₂–CH₂–CH(CH₃)–CHO

The aldehyde carbon is C1. Then C2 bears the methyl, C3 is CH₂, C4 carries the –OH.

**4-hydroxy-2-methylbutanal.** The –OH is a prefix because –CHO outranks it.

### Example 5: alcohol and a double bond

CH₃–CH=CH–CH(OH)–CH₃

The –OH is the principal group, so it takes the lower locant: number from the right. The double bond then starts at C3.

**pent-3-en-2-ol.**

### Example 6: two ketones and an ester

- CH₃–CO–CH₂–CO–CH₃ → **pentane-2,4-dione**
- CH₃–CH₂–COOCH₃ → **methyl propanoate** (the acid part is propanoate; the alkyl group attached to oxygen is methyl)

### Example 7: from name to structure

**3-methylbut-1-ene** → number a four-carbon chain, put the double bond between C1 and C2, and a methyl on C3:

CH₂=CH–CH(CH₃)–CH₃

<learning-block type="mistake" title="Errors that cost marks">

- **Choosing the longest chain but ignoring the principal group.** The parent must contain the –OH, –CHO or –COOH even if another chain is longer.
- **Numbering from the end nearer a substituent when a principal group is present.** The principal group comes first.
- **Counting di- and tri- in alphabetical order.** 3-ethyl-2,2-dimethylpentane: ethyl before methyl, regardless of the “di”.
- **Forgetting that the –COOH or –CHO carbon is C1.** It is always part of the parent chain.
- **Mixing trivial and IUPAC names.** “Isopropyl alcohol” is not an answer in a naming question; write propan-2-ol.

</learning-block>

## Practice

Name each structure.

1. CH₃–CH₂–CH(CH₃)–CH₂–CH₃
2. CH₃–C(CH₃)₂–CH₂–CH₃
3. CH₂=CH–CH₂–CH₃
4. CH₃–C≡C–CH₂–CH₃
5. CH₃–CH(OH)–CH₂–CH₃
6. HOOC–CH₂–CH(CH₃)–CH₃
7. CH₃–CH(Cl)–CH₂–CHO
8. CH₃–CH₂–O–CH₂–CH₃

Draw the structure.

9. 2,3-dimethylbutane
10. 3-ethyl-2-methylpentane
11. but-2-en-1-ol
12. 1,3-dinitrobenzene

## Take away

Naming is a fixed sequence: parent chain, principal group, numbering, substituents, alphabetical order. Every JEE organic question assumes this fluency, so practise until the sequence runs without conscious effort.
