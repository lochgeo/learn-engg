## Names carry structure

A coordination compound’s name should let you rebuild its formula. The rules below are the IUPAC convention used in board examinations and JEE. The key discipline is to name ligands alphabetically, to mark anionic complexes with an -ate ending, and to state the oxidation state of the central metal in Roman numerals.

## 1. Overall order

- Name the **cation first, then the anion**, as in any salt.
- Inside the coordination sphere, name **ligands first, then the metal**.
- Ligands are listed **alphabetically**, ignoring numerical prefixes such as di-, tri-, bis-, tris-.
- The whole coordination entity is named as one word; counter ions are separate words.

## 2. Ligand names

| Ligand | Name in a complex |
| --- | --- |
| $\mathrm{NH_3}$ | ammine |
| $\mathrm{H_2O}$ | aqua |
| $\mathrm{CO}$ | carbonyl |
| $\mathrm{NO}$ | nitrosyl |
| $\mathrm{Cl^-}$ | chloro |
| $\mathrm{CN^-}$ | cyano |
| $\mathrm{OH^-}$ | hydroxo |
| $\mathrm{O^{2-}}$ | oxo |
| $\mathrm{NO_2^-}$ (N-bound) | nitro |
| $\mathrm{NO_2^-}$ (O-bound) | nitrito |
| $\mathrm{SCN^-}$ (S-bound) | thiocyanato |
| $\mathrm{SCN^-}$ (N-bound) | isothiocyanato |

- **Neutral ligands** usually keep a special name (ammine, aqua, carbonyl); a few keep their molecular name.
- **Anionic ligands** end in **-o**.
- **Cationic ligands** (rare) end in **-ium**.
- Use **di-, tri-, tetra-** for simple ligands: diammine, trichloro.
- Use **bis-, tris-, tetrakis-** when the ligand name itself contains a numerical prefix or is complex, and place the ligand name in parentheses: bis(ethane-1,2-diamine).

## 3. The metal name

- If the complex is a **cation or neutral**, use the English name of the metal: cobalt, nickel, platinum.
- If the complex is an **anion**, change the metal name to end in **-ate**: iron → ferrate, copper → cuprate, cobalt → cobaltate, nickel → nickelate, platinum → platinate, silver → argentate, gold → aurate, tin → stannate, lead → plumbate.
- State the oxidation state of the metal in **Roman numerals in parentheses** immediately after the metal name: cobalt(III), iron(II).

## 4. Worked examples

1. $[\mathrm{Co(NH_3)_6}]\mathrm{Cl_3}$ → **hexaamminecobalt(III) chloride**. (Six ammine ligands; cobalt +3; three chloride counter ions.)
2. $[\mathrm{Co(NH_3)_5Cl}]\mathrm{Cl_2}$ → **pentaamminechlorocobalt(III) chloride**. (Alphabetical: ammine before chloro.)
3. $\mathrm{K_4[Fe(CN)_6]}$ → **potassium hexacyanoferrate(II)**. (Anionic complex, so iron → ferrate; Fe is +2.)
4. $[\mathrm{Ni(CO)_4}]$ → **tetracarbonylnickel(0)**. (Neutral complex; nickel is 0.)
5. $[\mathrm{Pt(NH_3)_2Cl_2}]$ → **diamminedichloroplatinum(II)**. (Two ammine and two chloro ligands; Pt +2.)
6. $[\mathrm{Co(en)_2Cl_2}]^+$ → **dichlorobis(ethane-1,2-diamine)cobalt(III) ion**. The prefix bis- is used because the ligand name already contains a number; alphabetically, chloro (c) comes before ethane-1,2-diamine (e).

## 5. Reversing: name to formula

Worked example: write the formula of **potassium hexacyanoferrate(III)**.

- Cation: $\mathrm{K^+}$; anion complex: $[\mathrm{Fe(CN)_6}]^{3-}$.
- Iron is +3; six cyanides contribute $-6$; net charge $+3-6=-3$, matching. Four potassium ions balance: $\mathrm{K_3[Fe(CN)_6]}$.

## 6. Bridging ligands

When a ligand connects two metal centres, prefix it with **μ-** (mu). Example: $[\mathrm{Cl_3Ru(\mu-Cl)_3RuCl_3}]^{3-}$ contains three bridging chlorides. Bridging ligands are cited before terminal ligands in the name.

## 7. A reliable naming method

1. Split the compound into coordination sphere and counter ions.
2. List ligands alphabetically, with correct prefixes and -o endings for anions.
3. Name the metal with -ate if the complex is anionic, and give its oxidation state.
4. Name counter ions last.

<learning-block type="mistake" title="Nomenclature errors">
- **Alphabetising the prefixes.** di-, tri-, bis- and tris- are ignored when ordering ligands; “dichloro” is alphabetised under c, not d.
- **Forgetting -ate for anionic complexes.** $\mathrm{K_4[Fe(CN)_6]}$ is hexacyanoferrate(II), not hexacyanoiron(II).
- **Using “amine” instead of “ammine” for $\mathrm{NH_3}$.** “Ammine” (double m) is the ligand name; “amine” is an organic compound class.
- **Omitting the oxidation state** or guessing it from the counter-ion charge alone.
</learning-block>

## Try it yourself

**A.** Name $[\mathrm{Co(NH_3)_4Cl_2}]\mathrm{Cl}$.

<details><summary>Show the reasoning</summary>

Four ammine and two chloro ligands: **tetraamminedichlorocobalt(III) chloride**. (ammine before chloro; cobalt +3 because 4 neutral + 2(-1) + x = +1 for the complex.)

</details>

**B.** Write the formula of **tetraamminecopper(II) sulphate**.

<details><summary>Show the reasoning</summary>

Complex cation $[\mathrm{Cu(NH_3)_4}]^{2+}$ plus sulphate $\mathrm{SO_4^{2-}}$ gives $[\mathrm{Cu(NH_3)_4}]\mathrm{SO_4}$.

</details>

**C.** Name $\mathrm{K_2[PtCl_6]}$.

<details><summary>Show the reasoning</summary>

Anionic complex: **potassium hexachloroplatinate(IV)**. Platinum is +4 because $x + 6(-1) = -2$.

</details>

## Check your understanding

Why is $[\mathrm{Co(en)_2Cl_2}]^+$ named **dichlorobis(ethane-1,2-diamine)cobalt(III)** and not **bis(ethane-1,2-diamine)dichlorocobalt(III)**?

<details><summary>Reveal</summary>

Ligands are listed alphabetically by the ligand name, ignoring prefixes. “chloro” (c) comes before “ethane-1,2-diamine” (e), so dichloro precedes bis(...). The prefix bis- is not counted in the alphabetising.

</details>

## Remember

- Cation before anion; ligands before metal; ligands in alphabetical order.
- Anionic ligands take -o; neutral ligands keep special names.
- Anionic complexes use the -ate form of the metal name.
- Use bis-, tris-, tetrakis- for complex ligand names and put them in parentheses.
- The oxidation state in parentheses is part of the name, not an optional label.
