## The big idea

Physics turns observations into statements we can compare, test, and share. A **physical quantity** is any property that can be measured. Every measurement has two parts: a number and a unit.

> A measurement without a unit is like a map without a scale: the number alone does not tell you what it means.

## Start here

### Number × unit

If a desk is 1.2 metres long, **1.2** is the numerical value and **metre (m)** is the unit. Together they describe the length. The same length can be written as 120 centimetres because the unit changed while the physical length stayed the same.

$$\text{physical quantity} = \text{numerical value} \times \text{unit}$$

Measurements are useful when different people can repeat them and understand the result in the same way. A shared system of units makes that possible. Without standard units, “three handspans” could describe very different lengths for different people.

### Base and derived quantities

Some quantities are chosen as foundations. Length, mass, and time are familiar examples. Other quantities are built from them: speed is distance divided by time, so its unit is metres per second.

| Quantity | Example unit | How it is described |
| --- | --- | --- |
| Length | metre (m) | A base quantity |
| Time | second (s) | A base quantity |
| Speed | metre per second (m/s) | Length divided by time |

## Worked example

### How far does a cyclist travel?

A cyclist rides at a steady $5\ \text{m/s}$ for $12\ \text{s}$. Distance is speed multiplied by time:

$$d = vt = (5\ \text{m/s})(12\ \text{s}) = 60\ \text{m}$$

The seconds cancel in the multiplication, leaving metres. The answer is a length, which is exactly what we expected.

## Try it yourself

**A ribbon is 2.4 m long. How many centimetres is that?**

<details>
<summary>Reveal the explanation</summary>

Since $1\ \text{m} = 100\ \text{cm}$, multiply by 100: $2.4\ \text{m} = 240\ \text{cm}$. The ribbon itself has not changed; only the unit used to describe it has.
</details>

## Remember

- Every measured quantity needs a number **and** a unit.
- A unit gives the number meaning and makes measurements comparable.
- Derived quantities combine simpler quantities; their units combine too.
